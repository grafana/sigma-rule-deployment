# Sigma rule validation

This folder doesn't contain an Action. Sigma Rule Deployment recommends the official [SigmaHQ Sigma Rules Validator](https://github.com/SigmaHQ/sigma-rules-validator) to check your rules against the [Sigma specification](https://sigmahq.io/docs/) before conversion.

For an example workflow, the validator's inputs, and its limitations, refer to [Validate Sigma rules](../../docs/set-up/workflows.md#validate-sigma-rules).
